# ติดตั้ง Google Sheets + Apps Script (ทำครั้งเดียว ประมาณ 10 นาที)

## 1. สร้าง Google Sheet
1. เปิด https://sheets.new (ล็อกอินบัญชี Google ของสาขา)
2. ตั้งชื่อไฟล์ เช่น `ลูกเทพศิลปศึกษา - ข้อมูล`

## 2. วางโค้ด Apps Script
1. ในชีต กดเมนู **ส่วนขยาย (Extensions) → Apps Script**
2. ลบโค้ดเดิมในไฟล์ `Code.gs` ออกทั้งหมด
3. คัดลอกโค้ดทั้งหมดจากไฟล์ [`Code.gs`](Code.gs) ไปวาง แล้วกด 💾 บันทึก
4. ที่แถบด้านบน เลือกฟังก์ชัน **setup** แล้วกด **▶ Run**
5. Google จะถามสิทธิ์ ให้กด **Review permissions** → เลือกบัญชี → **Advanced** → **Go to … (unsafe)** → **Allow**
   (ขึ้นคำว่า unsafe เพราะเป็นสคริปต์ที่เราเขียนเอง ยังไม่ได้ส่งให้ Google ตรวจ)
6. กลับไปที่ชีต จะมีแท็บใหม่: นักศึกษา, บันทึกติดตาม, ผู้ใช้, งาน, การส่งงาน, เช็คชื่อ, ใบลา, คะแนน

## 3. เพิ่มบัญชีอาจารย์
ในแท็บ **ผู้ใช้** ใส่หนึ่งแถวต่ออาจารย์หนึ่งคน:

| อีเมลหรือชื่อผู้ใช้ | ชื่อที่แสดง | บทบาท | รหัสผ่านชั่วคราว |
|---|---|---|---|
| teacher@cmru.ac.th | อ.สมชาย | อาจารย์ | ตั้งเองอย่างน้อย 8 ตัว |

- ล็อกอินครั้งแรกด้วยรหัสชั่วคราว ระบบจะบังคับให้ตั้งรหัสใหม่ และลบรหัสชั่วคราวออกจากชีตให้เอง
- ลืมรหัสผ่าน: ลบช่อง salt และ hash ของคนนั้น แล้วใส่รหัสชั่วคราวใหม่
- ปิดบัญชี: ใส่คำว่า `ปิด` ในช่อง "ปิดการใช้งาน"
- อย่าแก้คอลัมน์ salt และ hash เอง

## 4. Deploy เป็น Web App
1. ในหน้า Apps Script กด **Deploy → New deployment**
2. กดไอคอนเฟือง ⚙ ข้าง "Select type" → เลือก **Web app**
3. ตั้งค่า:
   - Execute as: **Me**
   - Who has access: **Anyone**
   (ต้องเป็น Anyone เพื่อให้หน้าเว็บบน GitHub Pages เรียกได้ ส่วนการกันคนนอกใช้ระบบล็อกอินแทน)
4. กด **Deploy** แล้วคัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)
5. ส่ง URL นี้ให้ผู้ดูแลเว็บ หรือนำไปใส่ใน `src/app.html` ที่บรรทัด `const SHEETS_API = '';` แล้วรัน `node scripts/build.mjs`

URL นี้ไม่ใช่ความลับ เพราะทุกคำขอต้องล็อกอินก่อน

## เมื่อแก้โค้ด Code.gs ภายหลัง
กด **Deploy → Manage deployments → ✏️ Edit → Version: New version → Deploy** ทำแบบนี้แล้ว URL เดิมจะยังใช้ได้
(ถ้ากด New deployment จะได้ URL ใหม่)

## ข้อควรระวัง
- แชร์ไฟล์ Google Sheet เฉพาะผู้ดูแล เพราะในไฟล์มีข้อมูลส่วนบุคคลของนักศึกษา (PDPA)
- Apps Script ตอบช้าประมาณ 1–3 วินาทีต่อครั้ง หน้าเว็บจะแสดง "กำลังโหลด" ระหว่างรอ
